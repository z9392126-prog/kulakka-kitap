# Құлаққа кітап — сайтты іске қосу нұсқаулығы

Сайт екі тегін қызметте тұрады, банк картасы керек емес:

- **Supabase**: аудио, видео, суреттер мен жазбалар сақталатын орын (1 ГБ файл орны тегін).
- **GitHub Pages**: сайттың өзі тұратын жер. Сілтемесі `сіздің-атыңыз.github.io/kulakka-kitap` сияқты болады.

Барлығына шамамен 30–40 минут кетеді. Компьютерден жасаған ыңғайлы.

Бумада мына файлдар бар:

| Файл | Не үшін |
|---|---|
| `index.html`, `app.js` | Сайттың өзі |
| `config.js` | Supabase мәліметтерін осында жазасыз (4-қадам) |
| `setup.sql` | Дерекқорды баптайтын мәтін (2-қадам) |
| `keepalive.yml` | Сайтты «ұйықтатпайтын» тапсырма (6-қадам) |

---

## 1-қадам. Supabase жобасын ашу

1. **supabase.com** сайтына кіріп, **Start your project** батырмасын басыңыз. Тіркелу үшін Google не GitHub аккаунты жарайды.
2. **New project** батырмасын басыңыз:
   - **Name:** `kulakka-kitap`
   - **Database Password:** күрделі құпиясөз ойлап тауып, бір жерге жазып қойыңыз (бұл сізге ғана керек).
   - **Region:** *Central EU (Frankfurt)*
3. **Create new project** батырмасын басып, 1–2 минут күтіңіз.

## 2-қадам. Дерекқорды баптау

1. Сол жақ мәзірден **SQL Editor** бөлімін ашыңыз.
2. `setup.sql` файлын Блокнотпен ашып, ішіндегі мәтінді **түгел** көшіріңіз.
3. Supabase-тегі бос өріске қойып, **Run** батырмасын басыңыз.
4. Төменде **Success** деген жазу шығуы керек.

## 3-қадам. Оқушы мен мұғалімге кіру құпиясөзін жасау

1. Сол жақ мәзірден **Authentication → Users** бөлімін ашыңыз.
2. **Add user → Create new user** батырмасын басыңыз:
   - **Email:** `okushy@kulakka-kitap.kz`
   - **Password:** оқушыларға беретін құпиясөз
   - ✅ **Auto Confirm User** белгісін қойыңыз
3. Тағы бір пайдаланушы қосыңыз:
   - **Email:** `mugalim@kulakka-kitap.kz`
   - **Password:** тек өзіңіз білетін құпиясөз (мұғалім материалды өшіре алады)
   - ✅ **Auto Confirm User**
4. **Маңызды:** **Authentication → Sign In / Providers** бөлімінде **Allow new users to sign up** белгісін **өшіріңіз** және сақтаңыз. Әйтпесе бөтен адамдар өздігінен тіркеліп кетуі мүмкін.

> Бұл поштаның шын болуы міндетті емес, ол тек кіру аты ретінде қолданылады. Оқушылар сайтта тек құпиясөзді енгізеді.

## 4-қадам. config.js файлын толтыру

1. Supabase-те **Project Settings** (тісті доңғалақ белгісі) → **Data API** не **API Keys** бөлімін ашыңыз.
2. Мына екеуін көшіріңіз:
   - **Project URL** (`https://....supabase.co` түрінде)
   - **anon / public** кілті, не **Publishable key** (`sb_publishable_...` деп басталады)
3. `config.js` файлын Блокнотпен ашып, тырнақшаның ішіне қойыңыз:

```js
supabaseUrl: "https://abcdxyz.supabase.co",
supabaseKey: "sb_publishable_....",
```

4. Файлды сақтаңыз.

> **secret** не **service_role** кілтін ешқашан қоймаңыз, тек **anon/publishable** кілтін қойыңыз.

## 5-қадам. Сайтты GitHub-қа салу

1. **github.com** сайтында тіркеліңіз (тегін).
2. Жоғарғы оң жақтағы **+ → New repository** батырмасын басыңыз:
   - **Repository name:** `kulakka-kitap`
   - **Public** таңдаулы тұрсын
   - **Create repository** батырмасын басыңыз
3. Ашылған беттегі **uploading an existing file** сілтемесін басыңыз.
4. Бумадағы **`index.html`, `app.js`, `config.js`** файлдарын сүйреп әкеліп тастаңыз, сосын **Commit changes** батырмасын басыңыз.
5. **Settings → Pages** бөліміне өтіп:
   - **Source:** *Deploy from a branch*
   - **Branch:** `main`, `/ (root)` → **Save**
6. 1–2 минуттан кейін сол бетте сайттың сілтемесі шығады:
   **`https://СІЗДІҢ-АТЫҢЫЗ.github.io/kulakka-kitap/`**

## 6-қадам. Сайтты «ұйықтатпау»

Тегін Supabase жобасына бір апта бойы ешкім кірмесе, ол тоқтап қалуы мүмкін. Мұның алдын алу үшін:

1. GitHub-тағы репозиторийде **Add file → Create new file** батырмасын басыңыз.
2. Файл атына дәл осылай жазыңыз: **`.github/workflows/keepalive.yml`**
3. `keepalive.yml` файлының мазмұнын көшіріп қойып, **Commit changes** батырмасын басыңыз.
4. **Actions** бөлімінде **Keepalive → Run workflow** батырмасын басып, бір рет тексеріңіз. Жасыл ✓ белгісі шықса, бәрі дұрыс.

Осыдан кейін ол күн сайын өздігінен жұмыс істейді.

## 7-қадам. Тексеру

1. Сайтты ашыңыз, ол бос, бірақ дұрыс көрінуі керек.
2. **Материал қосу** батырмасын басып, оқушы құпиясөзін енгізіңіз.
3. **+ Әңгіме қосу** батырмасын басып, алғашқы жазбаны салыңыз (мысалы, Жадыраның «Атамның ақылы» аудиосын).
4. Телефоннан QR-кодты сканерлеп, аккаунтсыз ашылатынын тексеріңіз.

## Қосымша: өз доменіңіз (.kz)

Сілтеме `kulakka-kitap.kz` сияқты болғанын қаласаңыз:

1. Қазақстандық тіркеушіден (мысалы, ps.kz, hoster.kz) домен сатып алыңыз (жылына ақылы).
2. GitHub-та **Settings → Pages → Custom domain** өрісіне доменді жазыңыз.
3. Тіркеушінің бетінде GitHub көрсеткен DNS жазбаларын қосыңыз.

Supabase → **Authentication → Users** бөлімінде пайдаланушыны тауып, **⋯ → Change password** (не **Send password recovery**) арқылы ауыстырасыз.
